# 🚀 Play Store Submission Checklist

## Pre-Submission Preparation

### ✅ Legal Documents
- [ ] Privacy Policy customized (all [BRACKETS] replaced)
- [ ] Privacy Policy hosted on public URL (verified accessible)
- [ ] Terms of Service prepared (optional but recommended)
- [ ] License file included (MIT License)
- [ ] Company information updated

### ✅ App Signing
- [ ] Keystore file generated (and backed up securely)
- [ ] Signing certificate password saved (in secure location)
- [ ] Certificate backup created (offline storage)
- [ ] Certificate expiration date noted (valid for 10+ years)

### ✅ Build Configuration
- [ ] Package name decided (e.g., com.yourcompany.endlesswheel)
- [ ] Version number set (1.0.0 recommended for launch)
- [ ] API level verified (minimum API 21)
- [ ] Target API updated (API 33 or higher)
- [ ] App name finalized

### ✅ Build & Export
- [ ] AAB file built in Godot
- [ ] AAB file tested (if possible)
- [ ] File size noted (under 150MB is good)
- [ ] Build output verified (no errors)
- [ ] AAB file backed up

### ✅ Store Listing Content
- [ ] App title finalized ("Endless Wheel")
- [ ] Short description written (80 chars max)
- [ ] Full description written (engaging, detailed)
- [ ] Category selected (Games > Action)
- [ ] Content rating submitted (PEGI/ESRB)
- [ ] Target audience selected (Everyone)

### ✅ Store Assets
- [ ] App icon prepared (512×512 PNG)
- [ ] 2-8 screenshots prepared (1080×1920 or 1920×1080)
- [ ] Feature graphic prepared (1024×500)
- [ ] Screenshots labeled with descriptions
- [ ] Promo video prepared (optional, but recommended)
- [ ] Promo video uploaded to YouTube (if applicable)

### ✅ Play Store Account
- [ ] Google Play Developer account created
- [ ] Developer fee paid ($25 USD)
- [ ] Account fully verified
- [ ] Payment method added
- [ ] Account email accessible

### ✅ Play Store Console Setup
- [ ] New app created in Play Console
- [ ] App name set correctly
- [ ] Category selected
- [ ] Content rating questionnaire completed
- [ ] App type selected (Game)
- [ ] Default language set (English)

### ✅ Release Configuration
- [ ] Release type selected (Production or Internal Testing)
- [ ] Release notes written
- [ ] AAB file uploaded
- [ ] Release details reviewed
- [ ] No warnings or errors shown

### ✅ Final Verification
- [ ] All required fields filled in Play Console
- [ ] No missing or incomplete sections
- [ ] Privacy policy URL valid and accessible
- [ ] Graphics load correctly
- [ ] Description displays properly
- [ ] No spelling or grammar errors
- [ ] All information accurate and current

## Submission Steps

### Step 1: Create App in Play Console
- [ ] Go to https://play.google.com/console
- [ ] Click "Create app"
- [ ] Enter app name: "Endless Wheel"
- [ ] Select type: "Game"
- [ ] Select category: "Action"
- [ ] Enter description/category information
- [ ] Accept terms and create

### Step 2: Fill Store Listing
- [ ] Title: "Endless Wheel" (50 chars)
- [ ] Short description: [Use template provided]
- [ ] Full description: [Use template provided]
- [ ] Language: English (US)
- [ ] Add all required graphics:
  - [ ] Icon (512×512)
  - [ ] Screenshots (minimum 2, recommended 4-6)
  - [ ] Feature graphic (1024×500)
  - [ ] Optional: Promo video

### Step 3: Set Store Listing Details
- [ ] Content Rating:
  - [ ] Complete IARC questionnaire
  - [ ] Select appropriate rating
  - [ ] Confirm rating
- [ ] Privacy Policy:
  - [ ] Paste URL to your privacy policy
  - [ ] Verify URL is accessible
  - [ ] Test privacy policy link works
- [ ] Target Audience:
  - [ ] Age range: All ages
  - [ ] Target audience: Everyone

### Step 4: Configure Release
- [ ] Go to "Release" section
- [ ] Create new release
- [ ] Release type: "Production"
- [ ] Upload AAB file
- [ ] Verify AAB upload succeeds
- [ ] Review APK details
- [ ] Verify target devices
- [ ] Add release notes: "Initial release of Endless Wheel!"
- [ ] Click "Review release"

### Step 5: Final Review
- [ ] Review all details one more time
- [ ] Verify app title and description
- [ ] Check app rating and content
- [ ] Confirm privacy policy URL
- [ ] Verify screenshots display correctly
- [ ] Check store listing preview

### Step 6: Submit
- [ ] Click "Start rollout to production"
- [ ] Confirm submission
- [ ] Note submission timestamp
- [ ] Save confirmation screenshot

## Post-Submission

### ✅ After Submission
- [ ] Check submission status in Play Console
- [ ] Note review start time
- [ ] Monitor for compliance issues
- [ ] Check email for Play Store notifications
- [ ] Document review timeline

### ✅ If Approved (1-3 days typically)
- [ ] App appears on Play Store
- [ ] Verify app is live and visible
- [ ] Test download and installation
- [ ] Verify gameplay works on device
- [ ] Share link with team/clients
- [ ] Announce launch

### ✅ If Rejected
- [ ] Read rejection reason carefully
- [ ] Note specific issues mentioned
- [ ] Fix issues based on feedback
- [ ] Update Privacy Policy if needed
- [ ] Re-export AAB with new version number
- [ ] Submit revised version
- [ ] Response typically 24-48 hours

### ✅ Post-Launch Monitoring
- [ ] Monitor app ratings and reviews
- [ ] Respond to user reviews
- [ ] Track download numbers
- [ ] Monitor crash reports
- [ ] Plan first update (if needed)
- [ ] Keep Play Console entries current

## Common Issues & Solutions

| Issue | Solution | Time |
|-------|----------|------|
| Privacy policy URL not working | Host on public server, verify HTTPS | 30 min |
| Content rating missing | Complete IARC questionnaire | 10 min |
| Screenshots wrong size | Resize to 1080×1920, re-upload | 15 min |
| Store listing incomplete | Fill all required fields (marked with *) | 20 min |
| AAB upload fails | Re-sign app, verify certificate | 30 min |
| App gets rejected | Review feedback, fix issues, re-submit | 1-3 days |
