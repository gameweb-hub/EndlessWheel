#### NOT Collected:
- ❌ User account information
- ❌ Email address
- ❌ Phone number

## 4. Data Security

### 4.1 Local Storage Security

**High Score Data:**
- Stored in encrypted format on your device
- Protected by device lock (PIN, fingerprint, etc.)
- Deleted if you uninstall the app

**How to Delete Your Data:**
1. Open Settings → Apps → Endless Wheel
2. Select "Storage" → "Clear Data"
3. All game data is immediately deleted
4. You can reinstall to start fresh

### 4.2 Our Security Practices

We implement security measures to protect your information:
- Encrypted local storage
- No unnecessary permissions
- Regular security updates
- Secure coding practices
- Third-party security audits (if applicable)

### 4.3 Security Limitations

While we implement reasonable security:
- No system is 100% secure
- Compromised devices may be vulnerable
- User responsibility: keep device secure
- We cannot guarantee absolute security
